今日を整え、今に集中する。

ZENnoMAは、日本の禅の思想と実践から着想を得た、日々の予定・集中・瞑想をつなぐアプリです。

Web で使う

無料で始められます。iPhone アプリは近日公開です。

ZENnoMA の考え方

いつもの一日に、心を向ける。ひとつ、ひとつ。

集中をゲームにするアプリも、SNSを開けなくするアプリもあります。ZENnoMA では、あなたの日常に寄り添って、より良い人生を送るためのサポートができれば幸いです。

25分

呼吸して、集中する。
それを、繰り返す。

  1. 呼吸

    ゆっくり吸って、さらにゆっくり吐く。これを6回。吐く息を長くすると、体は落ち着いていきます。呼吸に合わせて円相が描かれます。

  2. 集中

    決めたひとつのことに、時間を区切って集中します。カウントダウンはなく、カウントアップにすることで、少しずつ積み上げていくことを大切にしています。

  3. 繰り返す

    終わったら、ひと息ついて、また呼吸から始めましょう。集中した成果は、静かに積み上がり続けます。

一日を組んだら、
あとは実践していく。

集中・瞑想・予定枠を、ひとつのスケジュールに並べることで、今日1日をどのように過ごすのか、常に確認することができます。理想の1日を実践するためのサポートをさせていただきます。

決まったスケジュールはひな形として登録しておくことも可能です。アプリとWebは連携していて、同じ予定を見ることができます。

静かに坐る時間も、
大切にする。

静かに坐ることで体・呼吸・心を整えます。瞑想を通じて「今、ここ」を大切にすることは、高い集中力を発揮することにもつながります。

気が散ったり心が乱れたら、呼吸。

SNS を見すぎてしまった。怒りを表に出してしまいそう。なんだか不安だ。誰にでもあることです。アプリ内・ウィジェット・ロック画面からすぐに呼吸を始めましょう。

自分を失うものは、
そっと閉じておく。

iPhone では選んだアプリを、集中・瞑想のあいだと、決めた予定枠の時間だけ開けないようにすることができます。Webでは指定したURLをひらけなくなるようにすることも可能。どうしても開かなければいけないときは、呼吸をしてから5分間だけ開けます。

Web のサイトブロックには Chrome・Edge の拡張機能が必要です。呼吸してから5分だけ開くのは、iPhone と Web の両方で使えます。
