集中は、ひと呼吸から。

ZENnoMA は、90秒の呼吸で状態を整えてから、集中を始めるアプリです。

Web で使う

無料で始められます。iPhone アプリは近日公開です。

ZENnoMA の考え方

集中できないのは、意志が弱いからではない。状態が整っていないからだ。

集中をゲームにするアプリも、スマホを閉じ込めるアプリもあります。ZENnoMA がするのは、その手前のこと。90秒の呼吸で整えてから、始めます。

25分

呼吸して、集中する。
それを、繰り返す。

  1. 呼吸

    5秒吸って、8秒吐く。これを6回。吐く息を長くすると、体は落ち着いていきます。数えなくても、息に合わせて円相が描かれます。

  2. 集中

    決めたひとつのことに、25分・45分・90分。カウントダウンはなく、細い輪が静かに満ちていくだけです。

  3. また

    終わったら、ひと息ついて、また呼吸から。集中した時間は、そのまま積み上がります。

一日を組んだら、
あとは始めるだけ。

集中・瞑想・ほかの予定を、ひとつの予定表に並べます。その時間になると「今の時間は」に次のことが出て、押せば呼吸から始まります。

いつもの日はひな形から。iPhone ではカレンダーの予定も並べて見られます（端末の外には出ません）。iPhone と Web で同じ予定です。

静かに坐る時間も、
同じ場所に。

瞑想も同じアプリの中に。長さと、雨や川などの音を選んで、自然な呼吸のまま坐ります。

気が散ったら、呼吸。

SNS を見すぎてしまった。誰にでもあることです。アプリ・ウィジェット・ロック画面から90秒の呼吸をして、決めていた予定に戻ります。

気が散るアプリは、
閉じておく。

iPhone では、選んだアプリを、集中や瞑想のあいだと、決めた予定の時間だけ閉じます。どうしても開くときは、呼吸してから。

やらないこと

連続日数も、バッジも、ランキングもありません。広告を出さず、使い方の分析もしません。見えるのは、今日と今週に集中した時間。それだけです。

カレンダー・ヘルスケア・閉じるアプリの選択は、端末の外に出ません。予定と記録は、あなたのアカウントにだけ同期します。プライバシーポリシー

まずは、90秒。

Web で使う

基本の一周（呼吸・25分の集中・10分の瞑想）は無料です。そのほかの機能はサブスクリプションで使えます。
