プライバシーポリシー

制定日：【要記入：公開日】

YenSense株式会社（以下「当社」）は、「ZENnoMA」（iPhone・iPad のアプリ、Web アプリ、ブラウザの拡張機能を含みます。以下「本サービス」）での利用者の情報の扱いを、次のとおり定めます。

ZENnoMA の約束
  • 広告や利用状況の分析のための外部の仕組み（SDK）は入れていません。
  • 利用者の情報を売ることはありません。広告に使うこともありません。
  • カレンダー、ヘルスケア、アプリを閉じる設定は、利用者の端末の中だけで扱い、当社のサーバーには送りません。

1. 取得する情報と使い道

  1. アカウントの情報 — Apple または Google でログインしたときに各社から受け取る、利用者の識別子とメールアドレス（Apple で「メールを非公開」を選んだ場合は、Apple が用意する転送用のアドレス）。ログイン、アカウントの管理、問い合わせへの対応に使います。
  2. プロフィールと設定 — ユーザーネーム、国と地域、言語・外観・カラー・背景音などの設定、1日のリズム、帯の色。本サービスの表示と、端末のあいだの同期に使います。国と地域は、実践の地球儀に利用者の灯りを点すために使います。現在、ユーザーネームがほかの利用者に表示されることはありません。
  3. 利用者が入力した内容 — 予定（時刻・長さ・名前・メモ・色・音）、ひな形、今日の取り組むこと、型（集中や瞑想の手順）。表示と、端末のあいだの同期に使います。
  4. 集中と瞑想の記録 — 始めた時刻と終えた時刻、予定した長さと実際の長さ、最後まで続けたか、取り組んでいたことの名前。記録の表示と同期に使います。
  5. 端末の情報 — 端末ごとに作る意味のない番号、機種名（例：「iPhone 15 Pro」「Mac の Chrome」）、最後に使った時刻。1つのアカウントで同時に使える端末の管理（利用規約第2条）と、マイページの「使っている端末」の表示に使います。
  6. 購読の情報（有料プランを始めた場合）— 購読の状態・期間・更新の予定などを、購読の管理サービスや決済サービスから受け取ります。クレジットカードの番号など支払いの情報は、当社は受け取りません（Apple または決済サービスが扱います）。有料プランの提供と、問い合わせへの対応に使います。
  7. 問い合わせの内容 — 問い合わせの内容と返信先。返信と、本サービスの改善に使います。
  8. 自動で記録される情報 — Web サイトと Web アプリを配信する GitHub（GitHub Pages）が、安全のために、訪れた方の IP アドレスを記録します。この記録は GitHub が保管し、当社は受け取りません。

2. 端末の中だけで扱う情報（当社には送りません）

  • スクリーンタイム（アプリを閉じる機能） — 利用者が選んだアプリ・カテゴリ・Web サイトは、Apple が用意する中身の見えない印として端末の中で扱います。どのアプリをどれだけ使ったかを当社が知ることはありません。
  • ヘルスケア — 許可した場合に、睡眠と心拍を読み取って記録の画面に並べ、瞑想した時間をマインドフルネスとして書き込みます。ヘルスケアのデータは端末の外に出しません。
  • カレンダー — 許可した場合に、iPhone のカレンダーの予定を読み取り、スケジュールに並べて表示します。予定は保存せず、端末の外に出しません。
  • 通知とアラーム — 端末の中で予定して鳴らします。通知を送るための端末の識別子は集めません。

3. 第三者への提供

当社は、法令に基づく場合、人の生命・身体・財産の保護のために必要で本人の同意を得ることが難しい場合など、個人情報保護法で認められる場合を除き、本人の同意なく個人情報を第三者に提供しません。

4. 取り扱いの委託（使っている外部のサービス）

本サービスの提供のため、次のサービスに情報の保管や処理を委託しています。

  • Supabase — データベースとログインの基盤（アカウント・プロフィール・予定・記録などの保管）。保存先の地域：【要記入：Supabase のプロジェクトの地域】
  • Apple — Apple でのログイン、App Store での購入
  • Google — Google でのログイン
  • RevenueCat — 購読の状態の管理（有料プランを始めた場合）
  • Stripe — Web での支払い（Web で有料プランを始めた場合）
  • GitHub（GitHub Pages）— Web サイトと Web アプリの配信

これらには、米国など日本の外にある事業者が含まれます。外国にある第三者に個人情報を扱わせる場合は、個人情報保護法に従って必要な措置を取ります。各国の個人情報の保護の制度は、個人情報保護委員会のサイトで確かめられます。

5. 保存の期間と削除

アカウントがあるあいだ保存し、退会すると当社のサーバー上の利用者のデータを削除します（法令で保存が求められる情報を除きます）。退会は、本サービスのマイページからいつでも行えます。

6. 安全のための措置

通信の暗号化、データベースで本人の行だけを読み書きできる設定、情報にアクセスできる人の限定など、漏えい・紛失・改ざんを防ぐための措置を取ります。

7. 利用者の権利

利用者は、自分の個人情報の開示・訂正・削除・利用の停止などを求めることができます。下記の問い合わせ先までご連絡ください。ご本人であることを確かめたうえで、法令に従って対応します。多くの情報は、本サービスの中で直接確かめ、直し、削除することもできます。

8. 子どもの情報

本サービスは13歳未満の方を対象としていません。13歳未満の方の情報を取得していることが分かった場合は、削除します。

9. このポリシーの変更

変更するときは、このページで知らせます。大切な変更は、本サービスの中でも知らせます。

10. 言語

このポリシーには日本語版と英語版があります。内容に違いがある場合は、日本語版が優先します。
